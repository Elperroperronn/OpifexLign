# OpifexLign

Opifex Lign es una aplicación web desarrollada como proyecto académico para el curso Programación en Ambiente Web de la Universidad Técnica Nacional (UTN). La plataforma tiene como objetivo conectar ebanistas con clientes mediante un sistema que permite la publicación de muebles, la gestión de portafolios y el envío de solicitudes de cotización, promoviendo la digitalización de este oficio y facilitando la comunicación entre ambas partes.
